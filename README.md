### Practical: Write Text to a File

**Aim:**
To create a text file and write data into it using `std::ofstream`.

**Description:**
This program demonstrates basic file handling in C++. It uses the `ofstream` class to create and open a text file named `message.txt`. The program checks whether the file was opened successfully and then writes three lines of text into the file. Finally, the file is closed and a success message is displayed on the console.

**Concept Used:**

* `ofstream` – used for writing data to a file.
* `open()` – used to open a file.
* `close()` – used to close the file.
* File error checking using `if (!outputFile)`.

**Result:**
The program successfully creates `message.txt` and writes the specified data into it.
